# Modelo Geométrico 🐚 — Modelo de enrollamiento espiral (Raup, 1961-1966)

Implementación en Python del modelo geométrico de enrollamiento espiral de David M. Raup (`W`, `D`, `T`, `S`).

**Licencia:** AGPL-3.0-or-later. Ver [LICENSE](LICENSE).

> **⚠️ ADVERTENCIA:** Modelo teórico para fines educativos y de investigación; no sustituye análisis paleontológicos ni geológicos profesionales. Ver `docs/` para referencias originales.
